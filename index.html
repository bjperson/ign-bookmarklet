IGN Bookmarklet

Moteur de recherche pour les jeux de données IGN sur cartes.gouv.fr.

Permet de filtrer et télécharger les fichiers disponibles sur la Géoplateforme et sur le miroir opendatarchives.fr.

Installation

Glisser/déposer le lien ci-dessous dans votre barre de favoris :

IGN Bookmarklet

Utilisation

  1. Aller sur la page d'un jeu de données, par exemple : BD TOPO, ADMIN EXPRESS
  2. Cliquer sur le marque-page
  3. Le moteur de recherche apparaît sous l'en-tête de la page

Recherche

Tapez des mots-clés séparés par des espaces. Le nom du jeu de données est ajouté automatiquement.

  • gpkg 2025 D069 - GeoPackage, Rhône, édition 2025
  • shp lamb93 FRA - Shapefile Lambert-93, France entière
  • gpkg -shp -sql - GeoPackage uniquement (exclut SHP et SQL)
