# ign-bookmarklet

Ajoute un petit moteur de recherche à la page d'un jeu de données de l'IGN sur cartes.gouv.fr afin de permettre aux plus geeks d'entre nous de tirer parti de la convention de nommage des fichiers téléchargeables.

Permet également de générer une liste de liens vers les fichiers recherchés.
